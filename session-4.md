# 1. List all 6 Phases of SDLC in Order with One Line About Each

1. **Requirement Gathering & Analysis** – Collect and analyze the client's needs and system requirements.
2. **System Design** – Create the architecture, database design, and system specifications.
3. **Development (Coding)** – Developers write the code according to the design documents.
4. **Testing** – The software is tested to identify and fix bugs or defects.
5. **Deployment** – The completed software is released and installed for users.
6. **Maintenance** – The software is monitored, updated, and improved after deployment.


# 2. Three Differences Between Agile and Waterfall Models

1. **Approach**

   Agile: Development is done in small iterations (sprints).
   Waterfall: Development follows a fixed sequential process.

2. **Requirement Changes**

   Agile: Changes can be accommodated at any stage.
   Waterfall: Changes are difficult once a phase is completed.

3. **Customer Involvement**

   Agile: Customers provide feedback throughout the project.
   Waterfall: Customer involvement is mainly at the beginning and end.



# 3. Three Main Scrum Roles and Their Responsibilities

1. **Product Owner**

   Defines project requirements and prioritizes the product backlog.

2. **Scrum Master**

   Facilitates the Scrum process and removes obstacles for the team.

3. **Development Team**

    Designs, develops, and tests the product during each sprint.


# 4. What is a Sprint in Scrum? Mention its Typical Duration.

A Sprint is a fixed time period during which a Scrum team completes a set of planned tasks and delivers a working product increment.

Typical Duration: 1 to 4 weeks (most commonly 2 weeks).



# 5. Meaning of Jira Board Columns

1. **Backlog**
 List of all pending tasks, features, and requirements waiting to be worked on.

2. **To Do**

 Tasks that are ready to start but have not been worked on yet.

3. **In Progress**

 Tasks that are currently being worked on by the team.

4. **Done**

Tasks that have been completed and verified.

5. **Backlog → To Do → In Progress → Done**

This is the typical workflow followed on a Jira board.
