 # 1. What are the three main layers of software architecture? Write one line about each.

1. Presentation Layer (UI Layer) – Handles user interaction and displays information to the user.
2. Business Logic Layer (Application Layer) – Processes data and implements the application's rules and functionality.
3. Data Layer (Database Layer) – Stores, retrieves, and manages data in the database.



# 2. Define client and server in your own words with one real-life example.

1. Client: A client is a device or application that requests services or data from another system.
2. Server: A server is a system that provides services, resources, or data to clients.

Example: When you open YouTube in your browser, your browser acts as the client, and YouTube's computers that store and send videos act as the server.



# 3. Write 2 differences each between desktop apps, web apps, and mobile apps.

# Desktop Apps

1. Installed directly on a computer or laptop.
2. Can often work without an internet connection.

# Web Apps

1. Run inside a web browser and do not require installation.
2. Usually require an internet connection to access.

# Mobile Apps

1. Designed specifically for smartphones and tablets.
2. Can use mobile features such as the camera, GPS, and notifications.
