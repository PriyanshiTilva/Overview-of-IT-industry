# 1. Name 5 IT job roles and write one line about what each role does.?
Here are 5 common IT job roles and what they do:

1. Software Developer – Designs, develops, and maintains software applications and programs.

2. Web Developer – Creates and maintains websites and web applications.

3. Database Administrator (DBA) – Manages databases, ensuring data is stored securely and efficiently.

4. Network Administrator – Maintains computer networks and ensures smooth communication between systems.

5. Cybersecurity Analyst – Protects computer systems and data from cyber threats, attacks, and unauthorized access.

# 5.What is the difference between a developer and a tester? Answer in 2 lines.
A developer writes and maintains software code to build applications and features.
A tester checks the software for bugs, errors, and quality issues to ensure it works correctly.
