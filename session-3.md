# 1. Full Forms and One-Line Uses

**HTTP (HyperText Transfer Protocol)**

 Used to transfer web pages and data between a web browser and a web server.

**HTTPS (HyperText Transfer Protocol Secure)**

 A secure version of HTTP that encrypts data during transmission.

**FTP (File Transfer Protocol)**

 Used to upload and download files between computers over a network.

**SMTP (Simple Mail Transfer Protocol)**

Used for sending emails from one mail server to another.



# 2. Difference Between IPv4 and IPv6

 **IPv4** uses a 32-bit address and supports about 4.3 billion unique addresses (example: 192.168.1.1).

**IPv6** uses a 128-bit address and supports a vastly larger number of unique addresses (example: 2001:db8::1).

# 4. What do these HTTP status codes mean: 200, 301, 404, 500, 403?

**200 OK**

 The request was successful.

**301 Moved Permanently**

The requested page has been permanently moved to a new URL.

**403 Forbidden**

The server understood the request but refuses access.

**404 Not Found**

 The requested page or resource could not be found.

**500 Internal Server Error**

The server encountered an unexpected error.



# 5. Explain DNS hierarchy (root, TLD, domain, subdomain) with www.google.com as an example.

**Root (.)**

 The highest level in the DNS hierarchy.

**TLD (Top-Level Domain)**

 `.com`

**Domain**

`google`

**Subdomain**

 `www`

**Example Breakdown:**


1. www.google.com
│
 www      → Subdomain
 google   → Domain
 com      → Top-Level Domain (TLD)
The DNS system uses this hierarchy to locate and connect users to the correct website on the internet.
